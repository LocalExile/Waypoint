# Waypoint 0.5.0 — desktop improvements and Russian localization

This pre-release improves the desktop workspace and adds a Russian interface. Existing checkout selections,
settings, save backups and mod choices are retained.

## Changes

- Sidebar navigation replaces the top tabs. Mods and Backups use list/detail layouts with clearer controls,
  action availability and recovery guidance. Searches and unchanged service rows retain their state during polling.
- Keyboard navigation: **Ctrl+1–8** selects a page, **Ctrl+Tab / Ctrl+Shift+Tab** cycles pages, **Ctrl+F** focuses
  the current page's search, and **F5** refreshes local status. Page changes move focus into the chosen page.
- Integrated window controls replace the standard title bar. Native dragging, resizing and maximize/restore remain
  available. On Windows 11, hover over the maximize button for the system's **Snap Layouts** popup.
- Refined Waypoint's vector sidebar marker, text hierarchy, focus indicators, scrollbars and dark-theme controls.
  Windows High Contrast uses system colors. The minimum supported window size is **960 × 730** logical pixels.
- **English and Russian** are available under **Settings → Language**. Choose **Русский** to switch immediately;
  the choice is remembered after restart. English remains the default. Navigation, setup guidance, status labels,
  backup history, confirmations, tooltips and application accessibility names are localized.
- Backup restore/delete confirmations now use translated application dialogs with **Cancel** as the default.
  Escape cancels. Repository names, branch/PR titles, paths, hashes, in-game commands and raw logs retain their text.
- Added translation maintenance tooling and checks for resource coverage, placeholders, settings compatibility,
  technical-token preservation and both languages' layouts.

## Download and upgrade

Download **Waypoint-0.5.0-win-x64.zip** below. Close Waypoint, extract the complete ZIP into a new folder, then open
**Waypoint/Waypoint.exe**. Keep every supporting file and subfolder together, including **ru** for Russian resources.
The portable package includes its .NET Desktop runtime; no launcher installer is required.

Existing settings and backups remain in `%LOCALAPPDATA%\EmulatorWorkspaceLauncher`. Your selected LocalExile
installation and its client/saves remain in place. The ZIP includes a SHA-256 checksum and a release manifest with
the source commit and file hashes.

## Compatibility and limits

This remains an early alpha for Windows x64, standard LocalExile client/build folders, standalone PoE **3.29.3b**
and standard localhost ports. LocalExile still needs its own build/runtime prerequisites. Mod controls retain the
[0.4.0 requirements and limits](0.4.0.md). The language selector changes Waypoint's interface; native Windows UI,
raw runtime diagnostics and the game follow their own language settings.

Russian wording has not had a native-speaker review. Layout scaling was exercised in WPF checks; physical monitor
DPI changes and screen-reader listening were not tested. The native Snap Layouts popup and maximize/restore controls
were tested, but selecting a popup zone was outside the automation tool's accessible surface. Narrower snap zones
remain limited by the application's minimum size. This package remains unsigned and has no automatic updater.

## Validation

- Solution build with zero warnings/errors; **400 automated checks** across desktop, core, runtime bridge, mods,
  mod control/transport and branch/save integration.
- Running-app checks of all eight Russian pages at the minimum window size, live mouse/keyboard language switching,
  Cyrillic mod-status search, unchanged game commands and safe confirmation cancellation.
- Self-contained portable package verification and launch from a freshly extracted folder outside the development
  directory, including English/Russian resources and version 0.5.0.
