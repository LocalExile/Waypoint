# Waypoint 0.3.0 — first public alpha

Waypoint is a Windows desktop workspace manager for a local LocalExile source checkout.
This release is intended for local development and testing with the standalone PoE 3.29.3b client.

## Download and start

Download `Waypoint-0.3.0-win-x64.zip` from the repository's Releases page. Extract the whole ZIP into a new folder,
then open `Waypoint\Waypoint.exe`. Keep the supporting files and subfolders together. No installer is needed;
the launcher includes its .NET Desktop runtime. LocalExile's SDK, Git, Python, Node.js and client requirements still apply.

On first use, select a LocalExile checkout in Settings. Automatic lookup and manual folder selection are both available.
Follow Setup to prepare a separate client copy and create a local account, then use Play.

## Included

- Guided setup, repository discovery and a remembered manual location.
- Play, individual service controls, process ownership checks and graceful shutdown.
- Local/remote branch and upstream PR selection, including entry of a PR number.
- Current characters by default, optional fresh saves and configurable automatic backups.
- Save backup creation, commit history, restore and selected deletion.
- Gateway hot-reload monitoring and confirmed game-data override reload.
- Source/build commit badges, service/game logs, process measurements and a diagnostic preview.
- A self-contained Windows x64 portable package, quick-start guide, release manifest and SHA-256 checksum.

## Compatibility and current limits

- The standard LocalExile `Client`, `data` and Debug build layout and default localhost ports are supported.
  Custom client/build paths, custom ports, complex profiles and simultaneous environments are outside this release.
- Branch/PR switching requires the game closed, stops owned servers and builds the selected revision.
  It refuses local source changes instead of discarding them. It does not perform seamless live branch replacement.
- Compatible Gateway code edits can apply in game; compile failures keep old code running. Other edits may restart
  Gateway and return the player to login. Static initialization, extracted data, Auth and Patch can require restarts.
- Game-data reload uses the optional native helper and reloads SQLite overrides, not arbitrary extracted files.
- Automatic backups cover explicit launcher operations, not each external source save or watcher-triggered restart.
  Save restoration does not change source, client keys or game-data overrides.
- This portable alpha has no installer, code signing or automatic update service.

## Validation

The initial portable package was tested outside the development workspace against standard LocalExile `5fc27fa`.
Tests covered first use, backup, startup, disposable-character world entry, confirmed reload, graceful shutdown and
reopen. The source implementation passed 103 automated checks. Package verification checks every extracted file
against its manifest. See the repository's validation documents for the detailed scope.

## Reporting problems

Use the repository's Issues tab. Include the Waypoint version, LocalExile commit, what you clicked and what happened.
In Waypoint, open Logs → Diagnostic report, review the preview, then copy the report if useful. Remove any remaining
private details before sharing. Game files, databases, signing keys and passwords are not needed in a bug report.
