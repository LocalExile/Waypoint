# Waypoint 0.6.0 — account management

**Unreleased local review build.** No publication is authorized until the owner reviews it.

- New **Accounts** page with searchable accounts and characters, level, class/ascendancy, league and last played.
- Create, rename, set password, duplicate and delete accounts. Full copy is the duplicate default; **Start empty**
  creates only a new login. Full copies include progress and personal/guild stashes, with new identities and reviewed
  character names. Deletion requires the exact account name and defaults to Cancel.
- Automatic backups for all account changes, controlled directly on the page and managed in the existing Backups
  page. Backup history retains source and last-known Gateway commit metadata.
- Offline edits only: running games, services, watchers and ownership conflicts block changes. Browsing remains
  available while playing. Transactions, revision/database checks, collision checks and conservative schema support
  prevent partial or stale edits. Credentials travel through stdin without transcripts.
- English/Russian labels, existing themes and reading preferences, shared dialog frames and keyboard navigation.
  Ctrl+1–9 selects a page; Ctrl+6 opens Accounts, Ctrl+F searches and F5 reloads.

Requires Windows x64 and Python with SQLite 3.37+ for account reads/edits, plus the normal LocalExile prerequisites.
The portable ZIP includes Waypoint's .NET Desktop runtime. Extract the complete ZIP into a new folder and run
**Waypoint/Waypoint.exe**. Existing settings and backups retain their stable location.

Direct edits support the reviewed LocalExile storage format. New/unfamiliar schemas remain read-only until adapted.
Copies preserve opaque mod progress but do not rewrite arbitrary mod-specific references. No per-character editor
is included. See [account guide](../account-management.md) and [validation](../ui-review/accounts.md) before use.
