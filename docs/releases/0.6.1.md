# Waypoint 0.6.1 — waypoint emblem

**Local review build; not published.** This includes the account manager prepared for 0.6.0.

- Replace the sidebar arrow with an original PoE1-inspired waypoint: angular masonry, a circular glyph band and
  a curling central sigil. Light comes from the etched glyphs; the outer bricks have no glowing outline.
- The sidebar follows all 18 color schemes, Light/Dark/System modes and custom colors. Accent controls the
  engravings, Logo background controls the stone, and secondary text supplies neutral surface detail.
- Color-vision profiles and grayscale affect the complete artwork. Enhanced contrast suppresses the soft bloom;
  Windows High Contrast uses thickened, crisp system-colored engravings. The emblem is static, decorative and
  adds no keyboard stop or screen-reader announcement. Reading preferences retain the layout.
- Desktop, taskbar and window icons use the same geometry with a fixed blue glyph treatment. The Windows ICO
  contains ten transparent sizes from 16 through 256 pixels. No game assets or reference screenshot are bundled.

Extract the complete **Waypoint-0.6.1-win-x64.zip** into a new folder and run **Waypoint/Waypoint.exe**.
The portable package includes its .NET Desktop runtime; LocalExile prerequisites remain unchanged. Existing
settings and backups retain their stable location. This remains an unsigned Windows x64 early-alpha build.

See [the emblem design and validation](../ui-review/waypoint-emblem.md) for the actual references, generated-art
provenance, theme/native-size comparisons and limits. See [0.6.0 notes](0.6.0.md) for the included account manager.
