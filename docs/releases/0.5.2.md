# Waypoint 0.5.2 — consistent dialog windows

This pre-release fixes the standard Windows title bars left on Waypoint's secondary windows after 0.5.1.

## Changes

- Appearance and accessibility, the color picker, confirmations, setup instructions, account creation and diagnostic
  previews now share a themed title bar and Close button that follow the main workspace's design.
- Dialog captions follow the selected light/dark palette, reading font, text size and Windows High Contrast colors.
  Long titles use an ellipsis while retaining the full window title for accessibility.
- Native dragging, resizing and the system menu remain available. Modal dialogs stay with their owner and use a
  single Close control. Closing a preview cancels it; closing a confirmation never approves the action.
- Long confirmation, setup and account-form content can scroll while the action buttons remain visible.
  The account form starts with focus in the account-name field.

The main window's minimize/maximize controls and Windows 11 Snap Layouts behavior are unchanged.
The Windows folder picker remains a standard Windows dialog. No LocalExile runtime behavior changes.

## Download and upgrade

Download **Waypoint-0.5.2-win-x64.zip**, close Waypoint, and extract the complete archive into a new folder.
Open **Waypoint/Waypoint.exe** and keep all supporting files and subfolders together. Existing checkout selection,
appearance preferences, backups and mod choices are retained. The portable package includes its .NET Desktop runtime.

This remains an unsigned Windows x64 early alpha with no automatic updater. Requirements and the
[0.5.1 appearance/accessibility limits](0.5.1.md) are unchanged.

## Validation

- Solution build with zero warnings/errors and **852 automated checks**, including all six dialog types in default
  English, Russian with 150% OpenDyslexic text, and High Contrast resources. Checks cover scaled caption layout,
  accessible Close commands, native window styles and safe cancellation.
- Running-app checks of light/dark previews, custom caption dragging, resizing to the Appearance dialog's minimum
  size, its native system menu, nested color-picker framing and title-bar cancellation.
- Clean-source portable ZIP verification and launch from a new external folder, with matching source/version
  metadata, runtime files, Russian resources and font notices.

Physical display/DPI transitions, live Windows High Contrast toggles and screen-reader listening were not tested.
The desktop automation tool captures owned modal windows but does not expose them as separate keyboard targets;
their Close commands and accessible names were verified in-process, alongside native pointer checks.
