# Waypoint 0.5.1 — themes and accessibility

This pre-release adds appearance and reading preferences to Waypoint. Existing checkout selections, settings,
save backups and mod choices are retained. The default appearance remains dark Waypoint mint.

## Changes

- **Light, Dark and System** modes work with all **18 color schemes**. System follows Windows' application theme.
- **Custom colors** cover 27 interface roles, with common choices first and additional controls under
  **More interface colors**. Use a color wheel, keyboard-accessible sliders or exact hex input; light and dark
  custom colors are stored separately. Primary buttons and accent text can use different colors.
- **Reading options** include Segoe UI, Verdana and bundled OpenDyslexic, plus text sizes from 100% to 150%.
  No Windows font installation is needed. Larger text layouts keep navigation and Mods/Backups actions reachable.
- **Accessibility preferences** include red–green-friendly, blue–yellow-friendly and grayscale palettes,
  contrast protection/enhancement, stronger keyboard focus borders and reduced progress animation.
  Windows High Contrast takes priority, and Windows animation preferences are respected.
- **Live preview** updates the workspace. Apply saves; Cancel or Escape restores the previous appearance.
  **Ctrl+Shift+R** restores default appearance from the workspace without changing your checkout or saves.
- New controls and help text are available in **English and Russian**. Font license notices are included.

Open **Settings → Appearance and accessibility → Change appearance…** to get started.
See the [appearance guide](../appearance.md) for custom colors, keyboard controls and recovery.

## Download and upgrade

Download **Waypoint-0.5.1-win-x64.zip**. Close Waypoint, extract the complete ZIP into a new folder, then open
**Waypoint/Waypoint.exe**. Keep all files and subfolders together. The portable package includes its .NET Desktop
runtime; no launcher installer is required.

Existing preferences and backups remain in `%LOCALAPPDATA%\EmulatorWorkspaceLauncher`. Your LocalExile installation,
client and saves remain in place. A SHA-256 checksum is provided alongside the ZIP; the included release manifest
records the clean source commit and payload hashes.

## Compatibility and limits

This remains an unsigned Windows x64 early alpha with no automatic updater. LocalExile requirements and the
[0.4.0 mod-management limits](0.4.0.md) are unchanged. Appearance settings affect Waypoint, not the game.

Color-vision palettes and reading fonts are preferences, not a guarantee of improved readability for every user.
Arbitrary custom backgrounds can conflict with shared text colors; the editor warns about low contrast.
No complete accessibility-conformance claim is made. Physical monitor/DPI transitions, live Windows theme/High
Contrast toggles, screen-reader listening, native Russian review and participant accessibility testing were not
performed. System-mode selection and High Contrast resource behavior were checked without changing Windows settings.

## Validation

- Solution build with zero warnings/errors; **726 automated checks** covering desktop, settings, runtime bridge,
  mods, mod control/transport and source/save integration.
- All presets checked in light/dark, with all four color-vision profiles and ordinary/enhanced contrast.
  Additional checks cover malformed settings, separate custom colors, font loading, preview cancellation,
  High Contrast resources and larger-font layouts on all eight pages.
- Running-app checks of pointer/keyboard color editing, validation feedback, Apply/Cancel, restart persistence,
  the recovery shortcut, Russian controls, and 100%/150% reading layouts at 1240×900 and 960×730.
- Self-contained portable ZIP verification and launch from a freshly extracted folder outside the development
  directory, including matching version/source metadata, Russian resources and the bundled reading-font license.
