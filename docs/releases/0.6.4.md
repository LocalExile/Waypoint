# Waypoint 0.6.4 — accounts, tray controls and service status

A Windows x64 **early-alpha pre-release**, bringing together the changes since 0.5.2.

## Accounts and characters

- Browse and search accounts and their characters, including level, class/ascendancy, league and last played.
- Create, rename, change passwords, duplicate and delete accounts. Duplication defaults to a full copy of characters,
  progress and stashes, with an empty-account option and reviewed character names.
- Automatic backups are on by default and use the existing Backups manager. Account edits require the game and
  services to be stopped; stale data, ownership conflicts and unsupported save layouts block changes safely.

## Closing, tray behavior and startup

- Choose whether closing the window hides Waypoint beside the clock or exits it. Exit can leave LocalExile services
  running or stop them gracefully. The prompt shows service choices only when exiting, and its final button names
  the result. Settings uses the same explicit choices.
- Enable **Always ask when I close the window** to choose each time. Otherwise, **Remember this for next time** saves
  the selected behavior. Tray mode and service stopping on exit default off.
- An open game prompts Cancel or a one-time leave-running exit. Failed graceful shutdown keeps Waypoint open;
  no game or server is force-killed. Hiding to tray keeps operations and services running.
- Opening Waypoint again restores the existing workspace, including a hidden or minimized window. Another build or
  requested checkout produces a notice instead of silently opening a second workspace or changing your location.

## Status lights and appearance

- Patch, Gateway, Auth and Game have a persistent, compact status strip on every page. Green means ready/running,
  red stopped, amber starting/attention, and neutral unverified. Each light also has a name, state text and symbol.
  Click one to open its service details; clicking a light never starts or stops anything.
- Status lights follow custom status colors, all schemes and color-vision profiles. The glow is static. High Contrast
  uses system colors; High Contrast and increased contrast remove the glow for crisp outlines.
- A new PoE1-inspired waypoint emblem replaces the arrow. Its etched glyphs follow the app theme; desktop, taskbar
  and window icons use matching geometry. English/Russian and existing reading/accessibility options remain supported.

## Download and upgrade

1. Download **Waypoint-0.6.4-win-x64.zip**. The accompanying **.zip.sha256** file provides its checksum.
2. Exit the old Waypoint normally, using **Exit Waypoint** in its tray menu if hidden.
3. Extract the complete ZIP into a **new folder**, then open **Waypoint/Waypoint.exe**. Keep all supporting files together.

Your checkout selection, preferences and backups retain their stable location. The portable package includes its
.NET Desktop runtime; LocalExile prerequisites are unchanged. Account management additionally requires Python with
SQLite 3.37+ and a supported LocalExile save layout. Unfamiliar layouts can remain read-only. This package is unsigned
and contains no LocalExile checkout, game/client files, accounts or saves. Waypoint remains MIT licensed.

## Validation

The full regression suite passed **1,764 checks**, with one Python symlink test skipped. The Release build has no
warnings/errors. The actual portable ZIP is verified by checksum and all 415 payload hashes/sizes, then extracted
outside the development folder. UI checks include all schemes/modes/vision profiles, English/Russian, large reading
text, repeated close prompts and native tray callbacks. Status color previews use synthetic inventories; actual
checkout inspection is checked separately. Physical monitor/DPI changes and screen-reader narration are not claimed.
