# Waypoint 0.6.4 — persistent service status lights

**Local review build; not published.** Includes the previous account, branding, single-instance and close/tray improvements.

- A slim status strip below the current page always shows **Patch**, **Gateway**, **Auth** and **Game**, including
  while changing pages or scrolling. Each indicator has a name, state text and a distinct symbol.
- Normal status colors are green for a verified ready server/running game, red for stopped, amber for starting or
  attention, and neutral for status that has not been verified. Gateway watcher/restart gaps stay amber.
- The small static glow follows the selected semantic status colors. Color-vision profiles, grayscale and custom
  success/error/attention colors apply live. High Contrast uses system colors; High Contrast and increased contrast
  remove the halo for crisp outlines. No blinking or pulse animation is added.
- Click a light to open its existing service details on Play. The click never starts or stops a component.
- The strip uses the existing verified status snapshots and polling interval. Failed checks and checkout changes
  clear old success lights rather than presenting stale status as ready. Nothing is inferred from an operation request.
- Labels, tooltips and accessible names support English/Russian and the selected font/text size. All four remain
  arranged at the minimum window size, including 150% OpenDyslexic.

Extract the complete **Waypoint-0.6.4-win-x64.zip** into a new folder and open **Waypoint/Waypoint.exe**.
Exit an older Waypoint copy normally first, using its tray menu if hidden. Settings and backups remain in their
stable location. The unsigned Windows x64 package includes its .NET Desktop runtime.
