# Waypoint 0.6.3 — optional close to tray

**Local review build; not published.** Includes the previous account manager, waypoint emblem and single-instance improvements.

- The first-close dialog asks whether to **Keep Waypoint running in the tray** or **Exit Waypoint** first. Exit reveals
  its service choices. A single action names the result: **Hide to tray**, **Exit Waypoint** or **Stop services and exit**.
  Cancel leaves everything open. **Remember this for next time** saves the choice; uncheck it for a one-time action.
  Tray mode and stopping services on exit both default off.
- **Settings → Window behavior** uses the same explicit choices and wording. Enable **Always ask when I close the window**
  to keep choosing each time. Remember starts unchecked in that mode; remembering a choice turns Always ask off.
- A hidden workspace has a Waypoint icon in the Windows notification area beside the clock, possibly under the
  hidden-icons arrow. Click it to return, or right-click for **Open Waypoint** and **Exit Waypoint**.
  Opening the same EXE again also restores the existing window.
- The minimize button continues to minimize to the normal taskbar. Hiding keeps operations and services running;
  an explicit exit still waits for an active build/runtime/data operation to finish.
- Optional service shutdown uses the existing graceful stop, with fresh inspection before and after. If the game
  is open, cancel to close it first or choose **Exit and leave running** for this exit. A shutdown/verification failure
  keeps Waypoint open with feedback. No game or server is force-killed.
- Hidden workspaces pause periodic status inspection, refresh when reopened, and keep their single-instance ownership.
  Notification-area registration must succeed before the workspace is hidden. Explorer taskbar recreation re-registers
  the icon, with a visible-window fallback if registration fails.
- The prompt, preference and tray menu support English/Russian, the selected theme/reading settings and High Contrast.
  The shell icon matches the Windows desktop icon.

Extract the complete **Waypoint-0.6.3-win-x64.zip** into a new folder and open **Waypoint/Waypoint.exe**.
Exit older Waypoint copies normally first; if hidden, use their tray menu. Existing settings/backups stay in their
stable location. The unsigned Windows x64 package includes its .NET Desktop runtime.

See [notification-area behavior](../tray-behavior.md) for lifecycle details and validation evidence.
